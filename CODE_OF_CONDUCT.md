# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) Code of Conduct (v2.1).

## Summary

We are committed to providing a welcoming and inclusive experience for everyone. We expect all participants to treat each other with respect and professionalism.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Instances of unacceptable behavior may be reported to bwi@cocoar.dev. All complaints will be reviewed and investigated.
